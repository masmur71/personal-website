# Masmur Toloni Harefa — Portfolio
Single-page English portfolio using Next.js App Router, TypeScript, Tailwind CSS and a Mathua-inspired dark design.
## Development
Run npm install, then npm run dev.
Verify with npm run typecheck and npm run build.
Static export: out/. Cloudflare Pages build command: npm run build; output directory: out.
## Content
Edit lib/content.ts for projects and app/page.tsx for biography, contacts and skills.
See TODO.md for missing content. Resume and contacts are intentionally unavailable until real data is provided.
The supplied logo is used in the header and browser tab.
